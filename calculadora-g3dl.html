📊 Agregar a Google Sheets

Para agregar productos directamente necesitas un Google Apps Script como "puente". Pega aquí la URL de tu Web App de Apps Script y el sistema enviará el producto.

de https://docs.google.com/spreadsheets/d/ID/edit
📋 Instrucciones para configurar el Apps Script
1. Abre tu Google Sheet → Extensiones → Apps Script
2. Pega este código y guarda:
function doPost(e) {
  var data = JSON.parse(e.postData.contents);
  var ss = SpreadsheetApp.openById(data.sheetId);
  var sheet = ss.getSheetByName("Productos") || ss.getSheets()[0];
  sheet.appendRow([
    data.id, data.titulo, "", "", data.categoria_id,
    data.categoria_nombre, data.subcategoria_id, data.subcategoria_nombre,
    data.producto_descripcion, data.precio, data.estado, "", data.referencia
  ]);
  return ContentService.createTextOutput(
    JSON.stringify({ok: true})).setMimeType(ContentService.MimeType.JSON);
}

function doGet(e) {
  return ContentService.createTextOutput(
    JSON.stringify({status:"ok"})).setMimeType(ContentService.MimeType.JSON);
}
3. Implementar → Nueva implementación → Tipo: Aplicación web
    Ejecutar como: Yo · Acceso: Cualquier usuario
4. Copia la URL y pégala arriba.
5. Coloca el ID del Sheet en el segundo campo.
